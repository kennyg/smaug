# DSPy: Build and Optimize Agentic Apps

DeepLearning.AI short course taught by Andrew Ng in partnership with Databricks. Covers building and optimizing agentic AI applications using DSPy and MLflow.

## Course Overview
Learn to automatically tune prompts and optimize complex agentic AI workflows using DSPy's signature-based programming model and MLflow's tracing capabilities.

## Learning Outcomes
- Understand DSPy framework and its core abstractions
- Write programs using DSPy's signature-based model
- Debug AI systems with MLflow tracing for visibility
- Use DSPy Optimizer to automatically improve accuracy
- Best practices for using DSPy in production

## Key Topics
1. **Signature-Based Programming** - Structured input/output definition
2. **Automated Prompt Optimization** - Replace manual tuning with automation
3. **MLflow Tracing** - Gain visibility into pipeline performance
4. **Few-Shot Learning** - Optimize few-shot examples automatically
5. **Model Switching** - Re-optimize when upgrading LLMs

## Why DSPy?
- Solves the problem of manual prompt engineering (time-consuming)
- Automates optimization when changing LLMs
- Maintains performance across model upgrades
- Essential for complex agentic workflows
