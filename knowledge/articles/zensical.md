# Zensical - A Modern Static Site Generator

Next-generation static site generator built by the Material for MkDocs team that addresses and overcomes the technical limitations of MkDocs.

## Overview

Zensical represents the evolution of static site generation, addressing limitations found in traditional approaches like MkDocs while maintaining the ease-of-use developers expect.

## Key Improvements

- Overcomes technical limitations of MkDocs
- Modern architecture for improved performance
- Better extensibility and customization options
- Designed by the team behind Material for MkDocs

- Knowledge bases
- Blog-style documentation sites
