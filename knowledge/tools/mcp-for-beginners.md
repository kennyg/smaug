# MCP for Beginners

Microsoft's open-source curriculum introducing the fundamentals of Model Context Protocol (MCP) through real-world, cross-language examples.

## Overview
MCP is framed as a universal translator for AI applications—like how USB ports let you connect any device to a computer, MCP lets AI models connect to any tool or service in a standardized way.

## Coverage
- **Languages:** C#, Java, TypeScript, JavaScript, Rust, Python
- **Topics:**
  - MCP fundamentals
  - MCP client setup
  - MCP server development
  - Model Context Protocol architecture
  - Security considerations
  - Service orchestration

## Key Features
- Hands-on code examples in multiple programming languages
- Focus on practical techniques for building modular, scalable, and secure AI workflows
- Session setup to service orchestration coverage
- 13,945 stars on GitHub
- Primary language: Jupyter Notebook
